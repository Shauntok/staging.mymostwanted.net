## 本地界面检查

- 首页（`/zh-cn`）：检查导航/公告、地图容器尺寸、地图完整态与州属放大态、州属 hover/click、返回完整地图，以及 Latest/Hot/标签区。完整地图里，新加坡须以普通地区同样的底色、hover 和进入方式显示，名称为“新加坡”；它独立于马来西亚州属/投稿地区，不应常亮或采用特殊高亮。点选州属或新加坡后，只显示当前地区并以柔和过渡完整放大到地图中央；名称位于上方中央且不过大，拖动时可向上下左右平移而不裁切地区形状。返回胶囊应同时有箭头与“返回”字样，返回后恢复完整地图。地图来源控件只在完整地图态显示于右上方；“地图资料与署名”和“geoBoundaries”两个小胶囊横向并排，点开说明时来源文字在这排下方出现，不应出现遮挡地图的白色大方框；进入地区详情时隐藏该控件。地图边界仍只供示意；不要把示意边界当作可信行政边界数据。
- 账号与邮箱验证（`/zh-cn/account`、`/zh-cn/account/signup`、`/zh-cn/account/verify`、`/zh-cn/account/forgot-password`、`/zh-cn/account/reset-password`、`/zh-cn/account/complete-profile`，并抽查 `/en`、`/ms`）：确认登录、注册、邮箱验证、密码重设和用户名初始化/修复的文案说明投稿仍未开放；验证邮箱不应显示成开启投稿的承诺。若使用获批的合成环境配置 Turnstile，检查 `/account` 和 `/account/verify` 两个验证邮件重发入口都显示挑战且通过后才可提交。未配置 Turnstile、SMTP、Supabase 时只检查安全失败/不可用状态；不要输入真实邮箱、发送真实邮件或尝试绕过安全验证。
- 账号删除（`/zh-cn/account` 同页）：`ACCOUNT_DELETION_ENABLED=false` 时应展示默认关闭说明且不显示申请按钮；不要提交删除/取消动作，也不要为预览而运行迁移。到期 Worker 虽已写入本地，但两个清理开关默认关闭、迁移未应用、未调度或验证，UI 不得暗示已可彻底删除。未来申请说明须披露：若最终删除，该账号历史用户名记录也会清除且不预留，名称可能被重新注册。若能以授权方式查看账号人工审核状态，确认文案说明账号仍受限、等待 Owner 审核，资料不会自动删除或转移；不点击申请或取消。
- 投稿草稿（`/zh-cn/submit`）：检查分区填写、必选马来西亚州属/联邦直辖区、社交链接 HTTPS 白名单、版本化声明与最终预览。证据图片应为选填，缺少已扫描图片只标普通风险。页面是**不可提交的 UI 草稿**：不要填真实人物资料；不应出现提交 API、上传控件、自动保存或持久化草稿。
- 我的投稿（`/zh-cn/submissions`）：查看登录回跳、空列表与服务不可用状态；本地没有真实投稿数据。
- 举报与反馈（`/zh-cn/report`）：查看搜索选择、字段校验、Turnstile 位置和等待/失败提示。若只有合成帖子，可快速更换搜索词，确认建议只反映最近一次查询；不要提交举报或反馈。Supabase 未连接、Turnstile 未配置时，空列表/不可用状态属于预期。
- 请求政策说明（`/zh-cn/requests`）：确认永久封禁申诉、内容更正及撤下入口明确关闭，页面没有代收请求的表单或会自动发送的联系方式。
- 后台工作台（`/admin` 或对应语言路径）：只用已经存在且获授权的本地 Owner/Admin 会话。登录要求 Owner/Admin、AAL2 与近期 TOTP；不可绕过认证预览。先看角色对应的 Widget、布局编辑、控件隐藏/恢复和拖拽/键盘上移下移。不要点“保存布局”或“重置 Admin 布局”。
  - Admin 界面：检查概览、举报队列、投稿队列、帖子修订、站内通知、运营分析、账号处罚、近期操作记录和 Storage 汇总的文案、空/错误状态与隐私提示。
  - Owner 专属界面（仅 Owner）：检查公开帖子管理、首页标签排序、后台人员管理、投稿风险词库、关键安全邮件、IP 封锁、Hot 门槛、证据可见性控制和账号删除审核队列。删除审核队列只能显示用户名、申请时间与固定审核原因（包括“Auth 删除状态待核实”），按 50 条一页；检查首末页、上一页/下一页、加载状态、空态，以及近期 TOTP 过期后明确的错误状态。它不提供删除、移交、解除限制操作；不得为预览创建待审账号。IP 面板的“配置已填写”提示必须明确说明它不验证代理头可信性，并保持警示色；不要创建/停用规则、改角色、处罚账号、发布/隐藏帖子、改变证据可见性、修改门槛或打开任何开关。
  - 若有合成投稿，只查看详情、审核历史、风险标签和证据状态。确认 Admin 不出现 Owner 专属高风险数据；证据预览默认关闭。不要触发审核状态、帖子内容、举报状态或通知状态写入。
  - 布局/后台面板在迁移未应用时显示禁用、空态或服务不可用属于预期；记录实际画面，不要为预览而运行 SQL 或绕过授权。
- 公共帖子详情（`/zh-cn/posts/<UUID>`）：只在有本地合成公开帖时检查公开预览、登录墙、Reaction 与分享素材边界。不得使用真实当事人资料、提交 Reaction 或生成/分享包含真实信息的素材；详情服务不可用状态不证明数据库权限正确。
- 澄清目录与详情（`/zh-cn/clarifications`、`/en/clarifications`、`/ms/clarifications` 及各自的 `/<UUID>`）：检查 Clarification 导航入口、空/服务不可用状态、三语与主题、澄清徽标、Mother 与公开 Son 的关联卡片，以及 Son 详情页上的反向提示。没有已迁移的合成数据时，目录显示不可用/空状态属于预期；原帖隐藏但保留澄清的中性隐私分支也没有本地数据可预览，不能据空态判定该场景已验收；不得伪造帖子来填充页面。检查请求澄清只在当前浏览器形成草稿，客服未配置时显示“暂未开放”，不会向站点提交、保存或自动发送。不要点击发布开关、创建/修订/重绑/撤下等写操作。
- 后台 Clarification 工具：只有在已有获授权的 Owner/Admin AAL2 + 近期 TOTP 会话时查看角色对应面板；未登录或 MFA 不可用时停留在安全登录状态，不绕过认证。确认 Admin/Owner 均有澄清管理工具，但 Owner-only 的发布开关、关系重绑和撤下决议不可向 Admin 显示。只看控件与空态，不改变布局、开关、帖子或关系。
- 地区浏览（`/zh-cn/areas`）：检查左侧州属/独立地区列表的公开帖子数、已选地区的 District 清单/计数和下方公开帖子。有公开帖的 District 应在州地图上显示可点击计数 Pin，并与左侧 District 计数和筛选联动；无真实帖子时不显示 Pin，不得造数。马来西亚州属、联邦直辖区、新加坡均为独立浏览入口；新加坡不得归入州属或投稿地区选项。没有授权、完整 District/帖子种子时，页面显示未配置/空状态，不得编造子地区或数量。
- 其他已实现页面（`/zh-cn/latest`、`/zh-cn/hot`、`/zh-cn/tags`、`/zh-cn/search`）：检查三语布局、无数据/关闭/不可用状态与导航。没有合成公开资料时应保持空态；不得为了填充页面创建虚构人物、帖子、计数或地区边界。

## 检查边界

- 高风险功能默认关闭。检查界面时不要启用投稿创建、附件上传/读取、投稿发布、IP 封锁、分析、备份或安全邮件。
- 不应用数据库迁移，也不配置外部服务。
- 此阶段只检查可见文案、布局和交互预期。数据库权限、限流、TOTP、审计记录、扫描器及环境开关仍须后续验证。
- 若页面显示公开内容或设置不可用，这是没有连接 Supabase 时的预期界面，不代表后台行为验证通过。
- 不要使用真实人物、企业或个人资料填充页面；若要反馈 UI 修改，请记录路由、屏幕元素、希望的文案/行为，并附截图。
- Clarification 的数据库 gate `clarification_publication` 默认关闭，Telegram 官方客服 URL 留空；目录数据暂不可读时不得通过运行迁移或打开 gate 来准备 UI 预览。

## UI 验收后的顺序

收到 UI 修改意见后先完成修改，并请产品负责人确认最终界面；随后重跑受影响的本地验证和浏览器检查。此阶段其余本地实现/验证可继续推进，不因 UI 验收待处理而停下。待 Vercel、域名和独立 Supabase Staging 实际配置就绪并获用户授权后，优先在受访问控制、`noindex` 的 Vercel Staging/Preview 中使用合成数据完成线上端到端验收。Phase 3 的当前状态与出口顺序汇总见 [`PHASE3_EXIT_AUDIT.md`](PHASE3_EXIT_AUDIT.md)。Production 环境与切流仍需单独配置及你的明确授权。
