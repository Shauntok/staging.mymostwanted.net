# Malaysia administrative boundary data permission request (draft)

Status: internal draft only. Not sent, signed, or a substitute for the data provider's application process.

The MyGeoportal FAQ says spatial-format boundary data is obtained by official application, identifies JUPEM / state land offices as relevant custodians for administrative boundaries, and directs applicants outside Government / public-university / data-provider categories to the relevant Data Provider Agency. Confirm the eligible applicant and correct agency before treating this as a formal application.

## English inquiry draft

**Subject:** Request for guidance and reuse permission for Malaysia administrative district boundary data

Dear National Geospatial Centre / relevant Data Provider Agency,

I am preparing MMWR, a public website that lets visitors browse reviewed public posts by Malaysian state and district. Before using any government geospatial material, I would like to confirm the correct data provider and application route, and request written permission or a suitable license for public reuse.

The MyGeoportal `MyGeomap/Msia_Coverage` service exposes the following administrative boundary layers for read-only inspection:

- Peninsula Malaysia — “District or Jajahan Coverage Administrative”, layer 2; metadata lists JUPEM and August 2019.
- Sabah and Sarawak — “District or Jajahan Coverage Administrative”, layer 8; metadata lists JTU / JTSS and 2018 / 2023 updates.

Please advise:

1. Which agency is the data provider/custodian for each layer, and which agency should receive an application from a privately operated website project?
2. Whether current, complete, machine-readable polygon data and stable state/district codes are available for all of Malaysia, including the Federal Territories and Sabah/Sarawak administrative divisions.
3. Whether the data may be copied into the website repository, simplified or otherwise transformed, cached on our hosting provider, and redisplayed publicly as an interactive map.
4. Whether this use may include a public-interest, user-submitted-content website that could later display clearly labelled advertising. If commercial use is not permitted, please state the applicable restrictions.
5. Required attribution, update cadence, disclaimer, derivative-data, and downstream redistribution terms.
6. The application form, supporting documents, fees, approval timeline, and whether a signed institutional letter is required for this applicant type.

We will not download, embed, redistribute, or use the service as a production source unless the relevant provider confirms the permitted scope in writing. We can provide a product description, staging preview, and intended attribution for review.

## Malay inquiry draft

**Subjek:** Permohonan panduan dan kebenaran penggunaan semula data sempadan daerah pentadbiran Malaysia

Tuan/Puan,

Saya sedang menyediakan MMWR, sebuah laman web awam yang membolehkan pelawat menelusuri hantaran awam yang telah disemak mengikut negeri dan daerah di Malaysia. Sebelum menggunakan sebarang maklumat geospatial kerajaan, saya ingin mengesahkan agensi pembekal data, saluran permohonan yang betul, serta mendapatkan kebenaran bertulis atau lesen yang sesuai untuk paparan awam.

Perkhidmatan `MyGeomap/Msia_Coverage` di MyGeoportal memaparkan lapisan sempadan pentadbiran berikut untuk semakan baca sahaja:

- Semenanjung Malaysia — “District or Jajahan Coverage Administrative”, lapisan 2; metadata menyatakan JUPEM dan kemas kini Ogos 2019.
- Sabah dan Sarawak — “District or Jajahan Coverage Administrative”, lapisan 8; metadata menyatakan JTU / JTSS dan kemas kini 2018 / 2023.

Mohon panduan tentang perkara berikut:

1. Agensi manakah pembekal/pemegang data bagi setiap lapisan, dan kepada agensi manakah projek laman web persendirian perlu mengemukakan permohonan?
2. Adakah data poligon digital yang terkini dan lengkap serta kod negeri/daerah yang stabil tersedia bagi seluruh Malaysia, termasuk Wilayah Persekutuan dan pembahagian pentadbiran Sabah/Sarawak?
3. Adakah data boleh disalin ke repositori laman web, dipermudah atau diubah suai, dicache pada penyedia hosting kami, dan dipaparkan semula secara awam sebagai peta interaktif?
4. Adakah penggunaan ini dibenarkan untuk laman web berkepentingan awam dengan kandungan yang dihantar pengguna, yang mungkin pada masa hadapan memaparkan iklan berlabel dengan jelas? Jika penggunaan komersial tidak dibenarkan, mohon nyatakan sekatan yang berkenaan.
5. Apakah syarat atribusi, kekerapan kemas kini, penafian, data terbitan dan pengedaran semula?
6. Apakah borang permohonan, dokumen sokongan, fi, tempoh kelulusan dan keperluan surat rasmi yang ditandatangani untuk kategori pemohon ini?

Kami tidak akan memuat turun, membenamkan, mengedar semula atau menggunakan perkhidmatan ini sebagai sumber produksi sehingga skop yang dibenarkan disahkan secara bertulis oleh agensi berkenaan. Kami boleh menyediakan penerangan produk, pratonton staging dan cadangan atribusi untuk semakan.

Sekian, terima kasih.

`[Organisasi / status undang-undang, jika berkenaan]`  
`[E-mel untuk dihubungi]`
