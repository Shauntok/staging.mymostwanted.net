No failed run may report success.
- Configure `MMWR_BACKUP_MAX_TOTAL_STORAGE_BYTES` explicitly. Confirm a missing/invalid budget fails before database export or remote artifact uploads; an initial inventory whose cumulative source bytes exceed the budget is rejected before Storage object downloads, cumulative arithmetic overflow fails closed, and a final inventory that grows beyond the budget cannot report success. This bounds source Storage bytes only; size worker temporary-disk capacity for source, encrypted, readback and decrypted copies plus database exports.
- Verify each remote artifact can be downloaded/decrypted once during upload verification and that the manifest can then be downloaded/decrypted again for parsing without colliding with existing temporary files.
